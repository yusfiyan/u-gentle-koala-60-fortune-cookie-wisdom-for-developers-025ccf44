# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written for the [make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

> The code you write at 2 a.m. will be reviewed by someone who slept well.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The program writes a single line of at most 120 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22, standard library only, no other file writes at runtime.
